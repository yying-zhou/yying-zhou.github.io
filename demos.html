Interactive Prototype

3DGS-PPGIS Value Annotation Instrument

3D Gaussian Splatting / Participatory Mapping / Multispecies Justice

A browser-based tool for annotating place-based values directly onto a photorealistic 3D scene. Participants tap a location in the scene, select a value type (recreational, aesthetic, wildlife habitat, avoidance), and add a free-text note. Pins are stored with 3D scene coordinates and dwell time.

THE QUESTION

Does the shift from 2D map to 3D immersive scene systematically surface different value types — in particular, wildlife habitat and spatially marginal values invisible in plan view?

TECHNICAL STACK

Single-file HTML · Canvas 2D (demo) → Spark.js / THREE.js (production) · Supabase + PostGIS · No build step · Deployable as GitHub Pages URL

Open-Data Study

Where Would a Co-living Intervention Actually Be Needed?

Spatial Analysis / Open Data / Helsinki Region

A map of the Helsinki region at 250-metre resolution, crossing structural loneliness risk against walking access to third places — the informal settings where unplanned social contact happens. It flags 686 cells holding roughly 64,000 residents, then argues that identifying the sites is where design work starts rather than where it finishes: three of the flagged areas turn out to need three incompatible interventions.

THE QUESTION

Where do the conditions for a shared-living intervention actually coincide — people structurally more exposed to isolation, living furthest from the places that produce everyday social contact?

TECHNICAL STACK

Python · GeoPandas · Statistics Finland Paavo & population grid · Helsinki Region Travel Time Matrix · OpenStreetMap / Overpass · Leaflet · Static site, no build step

Spatial analysis Open data Housing & wellbeing Data visualisation
